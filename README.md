# St. Xavier's Campus Tour & Pathfinding (SXC Navigator)

An interactive, web-based campus navigation and pathfinding tool for St. Xavier's College, Mumbai. This application utilizes Dijkstra's Algorithm to compute and render turn-by-turn directions across campus buildings, complete with interactive floor transitions, visual staircase cues, faculty directories, and campus gallery previews.

---

### Live Web Application
Link: [Launch Campus Pathfinder](https://tjassonawane-ctrl.github.io/campus-pathfinder/)

---

## Features

* Smart Pathfinding Engine: Step-by-step route calculation using Dijkstra's algorithm.
* Multi-Building Navigation: Connects ground-floor landmarks across main academic blocks and hostel facilities.
* Staircase Guidance & Previews: Visual identification for SSL, Foyer, Middle, and Hogwarts staircases.
* Faculty & Department Directory: Integrated directory for Arts, Science, and Commerce departments.
* Interactive Campus Gallery: High-resolution preview overlay for iconic campus locations.
